# 🕌 Обучение Намазу (Муаллим Намаз)

Современное интерактивное приложение для обучения намазу с нуля, поддерживающее **все 4 канонических суннитских мазхаба** и **направление прямого следования Сунне (саляфитский путь)**, с подробным учетом различий между **мужчинами и женщинами**.

---

## 🌟 Поддерживаемые мазхабы и направления

1. **Ханафитский мазхаб (Имам Абу Ханифа)**
   - Руки в кыяме: мужчины ниже пупка (правая рука охватывает левое запястье), женщины на груди.
   - Раф‘уль-ядейн: только при вступительном такбире и в 3-м ракаате Витра перед Кунутом.
   - Рукуъ: мужчины — горизонтально 90°, пальцы расставлены; женщины — легкий наклон, пальцы сомкнуты.
   - Саджда: мужчины — локти приподняты и разведены; женщины — компактно, локти прижаты к полу и бокам.
   - Ташаххуд: подъем указательного пальца на «Ля иляха» и опускание на «илля-Ллах».
   - Сидение: мужчины — ифтираш (на левой стопе); женщины — таваррук (обе стопы выведены вправо).
   - Витр: 3 ракаата подряд с такбиром и дуа Кунут перед рукуъ.

2. **Шафиитский мазхаб (Имам аш-Шафии)**
   - Руки в кыяме: выше пупка и ниже груди, чуть смещены влево к сердцу.
   - Раф‘уль-ядейн: в 4 местах (такбир, перед рукуъ, после рукуъ, подъем на 3-й ракаат).
   - Ташаххуд: палец поднимается на «илля-Ллах» и удерживается неподвижно до саляма.
   - Кунут: обязательная сунна во 2-м ракаате утреннего намаза Фаджр.
   - Сидение: таваррук в последнем ракаате.

3. **Маликитский мазхаб (Имам Малик)**
   - Руки в кыяме: основное мнение (машхур) — Садль (руки опущены вдоль тела); также признан Кабд (сложены на груди).
   - Раф‘уль-ядейн: только при вступительном такбире.
   - Ташаххуд: непрерывное движение указательным пальцем вправо-влево.
   - Салям: один обязательный салям направо.

4. **Ханбалитский мазхаб (Имам Ахмад ибн Ханбаль)**
   - Руки в кыяме: ниже пупка либо на груди (переданы оба мнения).
   - Раф‘уль-ядейн: в 4 переходах.
   - Ташаххуд: палец шевелится/указывает при каждом упоминании имени Аллаха.
   - Кунут: в намазе Витр после поясного поклона круглый год.

5. **По Сунне / Без мазхаба (Саляфитский путь)**
   - Руки в кыяме: строго на груди (правая рука охватывает левую кисть, запястье и предплечье).
   - Раф‘уль-ядейн: в 4 установленных достоверными хадисами местах.
   - Саджда: строго 7 опорных костей, локти приподняты («как крылья»).
   - Ташаххуд: непрерывное легкое шевеление пальцем во время чтения дуа с направлением взора на палец.

## 📱 Основные разделы приложения

- **Интерактивный симулятор намаза:**
  - 5 ежедневных молитв (Фаджр, Зухр, Аср, Магриб, Иша) + Витр.
  - Пошаговое проведение через каждый ракаат (Шаг 1: Намерение → Такбир → Кыям → Рукуъ → И‘тидаль → Саджда → Ташаххуд → Салям).
  - Наглядные векторные иллюстрации поз молящегося.
  - Арабский оригинал с огласовками (Харакатами).
  - Русская транскрипция для заучивания произношения.
  - Смысловой перевод каждого аята и дуа.
  - Аудио-воспроизведение произношения.
  - Персональные подсказки по положению тела под выбранный мазхаб и пол.

- **Раздел Омовения (Тахарат):**
  - Малое омовение (Вуду): 8 пошаговых шагов, 4 коранических фарда, дуа после омовения.
  - Полное омовение (Гусль): когда обязательно, пошаговый порядок.
  - Сухое очищение (Таяммум): когда совершается и как делать.
  - Действия, нарушающие омовение, с пояснениями различий по мазхабам.

- **Суры и Дуа:**
  - Короткие суры: Аль-Фатиха, Аль-Ихлас, Аль-Фаляк, Ан-Нас, Аль-Каусар, Аль-Аср, Ан-Наср, Аль-Кафирун.
  - Молитвенные дуа: Сана (Субханака и Вадджахту), Ташаххуд (Ат-Тахийят), Салават Ибрахимийя, Дуа Раббана, Дуа Кунут (Ханафи и Шафии).
  - Озвучивание арабского текста одним нажатием.

- **Электронный Тасбих:**
  - Реалистичный круговой счетчик с тактильной отдачей и звуком четок.
  - Готовые зикры: «Субханаллах» (33), «Альхамдулиллях» (33), «Аллаху Акбар» (33), «Астагфируллах», свободный счет.
  - Автоматический переход по цепочке посленамазового поминания.

- **Тест знаний (Квиз):**
  - 10 тематических вопросов по столпам намаза, ракаатам, омовению, различиям мазхабов и исправлению ошибок (Саджда ас-Сахв).
  - Мгновенная проверка, подробные объяснения к каждому ответу и итоговый балл.

- **Справочник и настройки:**
  - 9 обязательных условий намаза (Шарт) и столпы (Рукн).
  - Частые ошибки новичков и способы их устранения.
  - Полная сравнительная таблица положений 5 богословских школ.

## 🛠 Технологический стек

### Android (Kotlin + Jetpack Compose)
- **Язык:** Kotlin 1.9.20
- **UI:** Jetpack Compose (Material Design 3)
- **Архитектура:** Clean Architecture / MVVM, разделение на `data`, `repository`, `ui/screens`, `ui/components`, `ui/theme`
- **TTS:** Android TextToSpeech для озвучивания арабских молитв

### Companion Web Live Preview (PWA)
- **Фреймворк:** React 19 + Vite 8
- **Стилизация:** Tailwind CSS 4
- **Иконки:** Lucide React
- **Звук:** Web Audio API (синтез тонов четок) + SpeechSynthesis (арабское и русское произношение)

## 🚀 Запуск и сборка

### Android Studio
1. Откройте корень репозитория в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите проект на эмуляторе или реальном устройстве с Android 8.0+ (API 26+).

### Web Live Preview
```bash
cd web
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```
Приложение доступно в браузере по адресу `http://localhost:5173`.
